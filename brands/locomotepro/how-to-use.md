# How to use this design system

A short guide for the marketing team. You do not need to be a designer. This page is the single source for LocomotePro colours, fonts, logos, building blocks and writing rules, and Claude reads it every time you ask for a LocomotePro design.

## Asking Claude to make something

Name the system in your request: "using the LocomotePro Design System". Say the size, the product, the audience and the one message. Examples that work well:

- "Make a 1080x1080 social post for LP Core S using the LocomotePro Design System."
- "Make a 1080x1920 story about the 1 August 2026 GPS mandate using the LocomotePro Design System."
- "Make a 6-slide sales deck for LocomotePro Fleet using the LocomotePro Design System."
- "Write an EN and BN caption in LocomotePro voice for a post about family safety with LocomotePro Home."
- "Make a one-page pricing sheet for LocomotePro Home in Bangla and English using the LocomotePro Design System."
- "Make a LinkedIn banner, 1500x500, for LocomotePro using the LocomotePro Design System."

Tips:
- Give real facts: prices in ৳, places (Dhaka, Chattogram), the mandate date. Claude will not invent numbers for you.
- If a draft feels off, say what to change ("more cyan", "shorter headline", "lead with the price").

## Which colour goes with which product

| Product | Lead colour |
| --- | --- |
| LocomotePro (Pro) and LocomotePro Fleet, businesses | **Electric Blue** #3B6FF5 |
| LocomotePro Home / Lite, car owners and families | **Cyan** #2DD4E0 |
| The platform as a whole, "one platform" messages | **The blue to cyan gradient** |

In posts, colour also carries the theme: cyan for platform and Lite, **amber** #F6A93B for the mandate and cost, **green** #2BD17E for value and offers. Backgrounds stay deep navy (#05091A, #0B1330).

## English and Bangla

- Every customer-facing piece ships in English **and** Bangla. Both say the same thing.
- Write English that translates cleanly: short sentences, no idioms.
- Bangla is set in Hind Siliguri. Prices use ৳; use Bengali numerals (০১২৩) where they read naturally.
- Social captions: EN and BN together, one call to action at the end, hashtags last (#LocomotePro #GPSBangladesh).
- Have a native speaker check the Bangla before anything goes live.

## Logo do's and don'ts

Do:
- Always use the icon **with** the "LocomotePro" wordmark in Bangladesh. The icon alone is not yet recognised.
- Keep clear space around the icon equal to its own height.
- Keep the icon at least 24px tall on screen and 10mm in print.
- Use it on the dark navy or the light #EEF3FB background.

Don't:
- Recolour the mark or the wordmark ("Pro" is always cyan).
- Stretch, rotate, outline or add shadows or effects.
- Place it on busy photos or low-contrast backgrounds.
- Separate the icon from the name, or change the casing.

## House rules for every word

- **No emoji.** Ever. The only symbol allowed is ✓ inside a badge.
- **Sentence case** for headlines and buttons. ALL CAPS only for small mono labels like `LIVE FLEET MAP · BANGLADESH`.
- **No em dashes.** Use commas, colons or parentheses.
- **"LocomotePro"**: one word, capital P. "LocomotePro Lite" or "LocomotePro Home", never "Lite" alone the first time.
- **BRTA** always in capitals.
- **The mandate date** is always written in full: **1 August 2026**.
- Say "we aim to" and "typically", never "guaranteed". Mark demo screens "*Sample data". Prices "exclude VAT".
- Skip "revolutionary", "world-class" and "seamless". Use a number instead.

## Downloading a logo or a finished design

- **Logos and graphics:** open **Assets**, pick the Logos or Graphics group, open the file and use its download button. `logo.png` is the main mark (transparent background); `mark.svg` is the small square icon for tabs and app icons.
- **A design Claude made for you:** open the design Claude published, then use its download or export option (PNG for social posts, PDF or PPTX for decks). If you do not see the format you need, ask Claude: "Give me this as a PNG at 1080x1080."

## Asking for changes to the system

- **Ask Claude:** "Update the LocomotePro Design System: change the amber to #F2A030 and add a note that amber is for the mandate only." Claude updates the system and everything made afterwards follows it.
- **Edit on the page:** if you have edit access, open **Colors** (or another token page), click a value, change it and save. Everyone using the system sees the change.
- Keep a short note of what changed and why, so the team knows. Big changes (a new colour, a new font) should be agreed with the brand owner first.
